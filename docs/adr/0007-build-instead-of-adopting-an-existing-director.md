# Build instead of adopting an existing director

Shotkit, HVE Video Director, and City Director were evaluated because they address similar video-directing work, but none matches Forger's exact intended workflow and contract. Forger will therefore be built rather than adopted from one of them so its behavior is not compromised to fit another tool's concepts or boundaries; revisit this decision if one later satisfies Forger's required artifact, Approval, Visual Board, Provider Profile, and generation-only boundaries with less ownership cost than maintaining Forger.
